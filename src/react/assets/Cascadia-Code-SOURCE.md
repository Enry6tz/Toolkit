# Cascadia Code

`cascadia-code-latin.woff2` is the unmodified variable Latin, upright webfont
from `@fontsource-variable/cascadia-code` version 5.3.0. It supports weights
200–700. The local CSS family alias is `AI Context Cascadia Code`; the font
software and its embedded names have not been altered.

- Download: <https://registry.npmjs.org/@fontsource-variable/cascadia-code/-/cascadia-code-5.3.0.tgz>

request and does not apply a font to the host application.
